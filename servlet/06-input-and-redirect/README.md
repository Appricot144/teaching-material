# 6章 入力を受け取り、結果を返す

4章では、Servlet class で HTML を組み立てて返す方法を見ました。5章では、JSP を使って、HTML のひな形に値を入れて返す方法を見ました。どちらも、ブラウザに頼まれたページを返すやり取りです。

Web アプリでは、ユーザが入力した値を受け取り、それを使って何かを変え（データを追加するなど）、その結果を返すやり取りもあります。この章では、この「入力を受け取る → 処理する → 結果を返す」という流れを、果物を追加して一覧を見るアプリを作りながら見ていきます。

- 1節: フォームから、果物の名前を受け取る
- 2節: 受け取った名前を確かめて、果物のリストに追加する
- 3節: 追加したあとの一覧を返す
- 4節: 結果の返し方に使う道具として、リダイレクトの仕組みを知る
- 5節: リダイレクトを使って、`POST` の二重送信を防ぐ
