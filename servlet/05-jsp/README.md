# 5章 JSP

Java の文字列で HTML を書く代わりに、JSP を使って HTML を返す方法を見ていきます。前の章ではこのようなページを動的ページと言いました。この「動的ページ」をどのようにして作るのかを5章では扱います。動的ページを作るための仕組みとしてJSPを取り上げ、JSP が Tomcat の中でどう動くのかと、Servlet class から JSP へどう値を渡すのかを説明します。

> 実はJSPのような仕組みのことをテンプレートエンジンといいます
