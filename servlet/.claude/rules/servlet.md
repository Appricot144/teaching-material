# servlet 教材のルール

`servlet/` の教材を書く・直すときに従うルール。全ドキュメントで共通のルールは、リポジトリのルートの `.claude/rules/writing.md` に従う。

## 想定する読者

プログラミングの基本的な構文を覚えて、プログラムを書き始めた人を読者とする。

読者ができること:

- 入力を受けて出力を返す簡単なプログラムを書ける
- ファイルを開ける
- 簡単な HTML を書ける

読者が知らないこと:

- ハイパーテキストとは何か
- サーバとクライアントの概念

## 参考文献として紹介する資料

公式ドキュメントとして、次のようなものを紹介する。

- Jakarta EE の仕様（Jakarta Servlet など）
- Tomcat のドキュメント
