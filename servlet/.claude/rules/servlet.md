# servlet 教材のルール

`servlet/` の教材を書く・直すときに従うルール。全ドキュメントで共通のルールは、リポジトリのルートの `.claude/rules/writing.md` に従う。

## 想定する読者

プログラミングの基本的な構文を覚えて、プログラムを書き始めた人を読者とする。

読者ができること:

- 入力を受けて出力を返す簡単なプログラムを書ける
- ファイルを開ける
- 簡単な HTML を書ける

読者が知らないこと:

- ハイパーテキストとは何か
- サーバとクライアントの概念

## 他のページの指し方

本文で他のページを指すときは、次のように書く。

- 隣のページ: 「次のページ」「前のページ」
- 同じ章の離れたページ: 「n節」
- 他の章のページ: 「m章n節」
- 章: 「n章」

「次のファイル」のように「ファイル」とは書かない。読者にとって教材は読み物なので、手元のファイルを連想させないようにする。

「ページ」は Web ページの意味でも使う。同じ段落の中で、2つの意味が並ばないようにする。
